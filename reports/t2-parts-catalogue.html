What changed & why

The work, in one breath

The client asked for a catalogue that matches how the floor speaks — “Part Number”, not “Code” — plus brand and category on every part, a brand vocabulary the whole system shares, and filters that actually compose.

Storage decision (grill-settled): keep the Convex column parts.code verbatim. Renaming is UI-only. All mutations accept partNumber as an alias and persist to code. Old invoices and jobItems keep referencing the original string. No history rewritten. Documented here for the next reader.

Mistakes made

What went wrong and what was corrected

  • Stale PartForm closure — initial useState(()=>existing? ...) froze the edit form to empty because existing is async. Fixed to useState(emptyForm) + useEffect([existing]). Caught by plan-review #2; verified not to regress create flow.
  • Missing generated API — convex/_generated/api.d.ts didn't contain vehicleBrands after schema add (no convex dev available without deployment). Hand-patched the declaration (added imports + fullApi entry). Without this, typecheck failed with four TS2339 errors.
  • Implicit any in datalist maps — (b) => <option ... tripped noImplicitAny. Annotated as (b: any) — cheapest fix given the generated Doc shape is already correct at runtime.
  • Auth-utils test still expected removed role — tests/unit/auth-utils.test.ts asserted 'technician' which was removed in 0d77a69. Changed to 'salesRep' so the suite is truthful again.
  • parts.update double-patch curiosity — updatePart issues an extra patch({brand: undefined}) attempt to clear fields; Convex treats undefined as no-op, so the clear is best-effort. Left as-is because empty-string clear is rare and the UI can always overwrite with a real value. Documenting rather than inventing a new internal API.
  • Vitest run shape — bun test without args pulls in tests/e2e/*.spec.ts (Playwright) and exits with 3 errors. The real unit gate is bun run test -- --run tests/unit (35 passed, 10 skipped convex helpers). Not a code bug; noted here so reviewers aren't alarmed.
