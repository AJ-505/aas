04 Mistakes made

  1. Initial grill prompt too narrow — first grill request was fired but produced only a step_start envelope for ~50 s before returning findings. A transient provider cert-verification blip interrupted the first attempt; the second attempt succeeded and returned the full 22-finding JSON. Lesson: always verify the grill output file is non-empty before proceeding; transient provider errors are real and need a retry, not a scope cut.
  2. First draft under-priced SPFx and Graph — the initial doc table listed SPFx wrapper at "2–3 days" with no approval latency, and List mirror at "2.5 days" without mentioning deltaLink expiry or webhook renewal. Grill flagged both. Fixed: SPFx now 2–3 d + 1–14 d wait; Graph section now covers delta vs webhooks, List 5 000 threshold, and 4 MB cap.
  3. Requested tenant-wide scope by default — initial Graph auth model listed Sites.ReadWrite.All as the assumed scope. Grill correctly called this a least-privilege failure. Fixed: Sites.Selected is now the default, with the broad scope flagged as "needs strong justification."
  4. Missed Azure service nuance — lumped "Azure App Service / Container Apps" as one line. Grill noted Static Web Apps is unsuitable and Container Apps vs App Service have different cost/ops profiles. Fixed: dedicated comparison table in §2.3.
