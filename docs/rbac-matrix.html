01

Model Overview

● Full access ◐ Scoped access (assigned-own only) ● Unconditional override (Admin) — No access
ModelisAuthorized(role, allowed): null ⇢ deny · admin ⇢ true · else membership.

Admin

Unconditional bypass; user mgmt, rates, everything.

CSR / Advisor

Front desk: check-in, customers, appointments, labour lines.

Technician

Diagnose + work own jobs, request parts. No invoices, no customers.

Inventory Mgr

Parts catalogue, stock, approve/dispatch/reverse requests.

Finance

Invoices, approval, payments, labour & VAT settings.

Manager

All service ops, completes jobs, approves invoices, oversees.

Sales Rep

Leads, sales orders, deliveries, sales inventory exposure.
